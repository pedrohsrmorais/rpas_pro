# ── Notas de instalação ─────────────────────────────────────
# Após instalar as dependências, rode UMA VEZ:
#   playwright install chromium
# para baixar o binário do Chromium gerenciado pelo Playwright.
#
# No Windows, o Chrome deve estar instalado em:
#   C:\Program Files\Google\Chrome\Application\chrome.exe
# ou defina a variável de ambiente CHROME_EXECUTABLE_PATH com o caminho correto.
#
# No Linux, instale o Google Chrome:
#   wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
#   sudo dpkg -i google-chrome-stable_current_amd64.deb
